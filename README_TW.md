### 不支持破壞的方塊黑名單

- 重複型指令方塊

- 拼圖方塊

### 方塊添加指令過濾器

- 空氣
- 可替換方塊

## 🛠️ 客戶端指令

- `/bedrockMiner`：開啟/關閉
- `/bedrockMiner disable`：停用模組（開啟後模組將不會繼續處理）
- `/bedrockMiner behavior floor add <floor>`：添加層數至黑名單
- `/bedrockMiner behavior floor remove <floor>`：移除層數從黑名單
- `/bedrockMiner behavior block whitelist add <block>`：增加白名單方塊
- `/bedrockMiner behavior block whitelist remove <block>`：移除白名單方塊
- `/bedrockMiner task addRegionTaskConfig <name> <pos1> <pos2>`：添加區域任務到配置文件
- `/bedrockMiner task addRegionTask <name> <pos1> <pos2>`：添加區域任務(臨時性, 重啟遊戲後無效)
- `/bedrockMiner task fast <bool>`：啟用或停用快速處理
- `/bedrockMiner task clear`：清空任務
- `/bedrockMiner debug true`：開啟除錯模式
- `/bedrockMiner debug false`：關閉除錯模式

# 🛠️ 使用方法

使用前需準備好如下物品：

- 效率 V 鑽石/獄隨鎬
- 挖掘加速 II 烽火台
- 若干活塞
- 若干紅石火把 
- 多個史萊姆方塊 

### 啟動與關閉

- **啟動**：空手狀態下右鍵點擊基岩即可激活該模組。（請務必保持空手狀態） 👐
- **操作**：激活後，只需左鍵點擊基岩，模組就會自動嘗試破除基岩。 💥
- **關閉**：再次空手狀態下右鍵點擊基岩可以關閉該模組。 🚫

如果你覺得這個模組為你節省了很多時間，請不要吝嗇你的 Star 呀！🌟
